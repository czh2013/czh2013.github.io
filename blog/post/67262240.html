网站部署教程 进阶版

本期教程是《网站部署教程（简易版）》的进阶版本，包含了获取自定义域名、CloudFlare 加速与保护，以后还有别的部署方法。这里为了方便我就使用临时邮箱了。

📋 操作概览
  1. 获取域名（此处演示的是免费域名）
  2. 配置 CloudFlare
  3. 部署

第一步 获取域名

免费域名获取平台有很多，这里列举几个并且使用 Digitalplat Domains。

  • DigitalPlat Domains — 点击这里
  • ClouDNS — 点击这里
  • EU.org — 点击这里
  • DNSHe — 点击这里

以 Digitalplat Domains 为例，注册账号（注册时建议使用美国地址生成器）后来到主界面。

看到下面，去点一颗 Digitalplat Domains 的 GitHub 仓库的星，然后验证，会有个额外的插槽，也就是相当于可以获取 2 个免费域名。

然后再点击左边的 域名注册。

然后写上你自己想要的域名（注：有些域名可能需要额外收费）。

填好后点击 检查可用性，之后会来到这里。

现在我们注册 CloudFlare 账号 点击这里。

注册完后点击左侧的 域名。

点击右上角 新建域名。

选择第一个 连接域名。

把自定义域名填好后，点击 继续。

就会来到计划页面，这里可以根据自己来选择，选 免费计划 就差不多够用了。（注意：如果您显示了配置 DNS 页面，请看后面的步骤图。）

然后来到 更新域名服务器 页面。

把图片中指的那两个服务器复制到之前 DigitalPlat Domains 的域名配置界面，点击注册就好了。

要续费域名的话，点击 续费 那一栏，点击 申请免费续费。

然后返回 CloudFlare，找到最下面的 我已更新我的名称服务器 并点击，等待一会，CloudFlare 的显示应该是这样：

接着打开《网站部署（简易版）》的 GitHub 仓库 还没看？点击这里！

点击上方的 设置。

在左侧找到 页面 并点击。

在 自定义域名 里写上自己的域名。

随后返回 CloudFlare 页面，找到该域名下的 DNS 选项并点击。

点击添加，并按图中格式填，填 4 条。

类型 A 名称 @ IPV4 地址 185.199.108.153
类型 A 名称 @ IPV4 地址 185.199.109.153
类型 A 名称 @ IPV4 地址 185.199.110.153
类型 A 名称 @ IPV4 地址 185.199.111.153

填好后就是这样：

如果你想让域名前面加个 www 也可以访问，可以看下面的图片。

再返回之前的 GitHub 仓库页面，点 Save（保存）就好了。
